# X11 应用 Dock：交互与性能规范

## 布局和状态

保持经典系统图标和底部横向层次，78 px 面板保留 EWMH 占位。应用区域按可用宽度排列 52 px 图标、72 px 插槽；窄屏溢出进入“更多”。菜单、显示桌面是会话入口，不属于驻留应用。没有预设浏览器、音乐、商店等占位 APP。

应用数据来自用户驻留配置和 X11 实际窗口。同一应用的窗口合并为一个 APP logo，以 StartupWMClass、应用 ID、WM_CLASS 和可执行文件匹配桌面文件；未匹配时读取窗口自己的 `_NET_WM_ICON`，无图标才使用通用图标。底部短线表示正在运行，活动应用用亮色强调。

- 单窗口：点击活动图标最小化；点击非活动图标恢复并切换到对应工作区。
- 多窗口：点击循环切换；右键菜单列出各窗口，并提供最小化、关闭操作。
- 右键驻留：退出应用后图标保留。移除驻留不会关闭应用；正在运行的图标仍保留至最后一个窗口关闭。
- 拖拽驻留图标排序：10 px 阈值，插入线反馈，松开才保存，不逐帧写配置。
- 可拖入 `.desktop` 文件，也可从 XLaunch 右键驻留。系统中没有桌面文件的窗口仍可管理，驻留按钮不可用。
- 空驻留列表有效；旧版没有 launchId 的占位项不再显示。用户显式配置保留。
- 键盘方向键选择图标，Enter/Space 激活；提供焦点框、可访问名称、延迟提示。

## 配置

Qt QSettings：`ai-workspace-lab/XDock.conf`，遵循 `XDG_CONFIG_HOME`。
`applications/pinned` 为 JSON，顺序即驻留顺序。设置界面支持桌面 ID 或绝对 `.desktop` 路径。清空驻留不会关闭窗口。应用实际启动交由 gio，不在 shell 中执行桌面文件的 Exec 字段。

## 性能和会话隔离

默认禁用 Dock 放大和过渡。最大化/最小化交给窗口管理器；远程无合成会话即时切换。窗口更新由 XCB PropertyNotify 驱动、60 ms 合并；15 秒定时刷新只用于恢复。原子名称、桌面应用映射和图标有缓存；应用目录变动时刷新映射。时钟每 30 秒更新。

IPC `ai-workspace-lab.xdock.launch-events.<display>` 仅当前用户访问，按显示会话隔离，同一会话只运行一个 Dock。`pin` 消息只接收有效 `.desktop` 文件；X11 运行状态以窗口生命周期为准，启动通知不会制造永久运行项。

本次实现覆盖 X11/EWMH（IceWM、KWin X11）。Wayland 窗口枚举协议待单独实现；layer-shell 面板能力不代表 Wayland 任务管理已完成。
